# Dashboard de Rendimientos Financieros | Tesla y MGC

## Proyecto Académico

Este repositorio contiene un dashboard desarrollado en Power BI como parte del proyecto final del curso, enfocado en el análisis de rendimientos financieros de Tesla y MGC.

## Descripción del Proyecto

El proyecto tiene como finalidad analizar el comportamiento y desempeño financiero de ambos activos mediante herramientas de visualización de datos e indicadores financieros. A través del dashboard se presentan comparaciones de rendimientos, tendencias del mercado y métricas clave que permiten interpretar la evolución de los activos en distintos periodos.

## Características Principales

- Análisis de rendimientos financieros
- Comparación entre Tesla y MGC
- Visualización de tendencias
- Indicadores financieros interactivos
- Interpretación de comportamiento del mercado
- Dashboard dinámico en Power BI

## Herramientas Utilizadas
